# AquaMasterUzbekistan — Fish Atlas 🐟🇺🇿

**AquaMasterUzbekistan — Fish Atlas** — bu professional, kengaytiriluvchi, zamonaviy arxitekturaga ega Telegram bot platformasi bo'lib, chuchuk suv akvarium baliqlari, ularning taksonomiyasi, biotoplari, suv kimyosi parametrlari, oziqlanishi, ko'payishi, kasalliklari va parvarishlash bo'yicha to'liq raqamli ensiklopediya va akvarium yordamchisi sifatida xizmat qiladi.

Barcha foydalanuvchi interfeysi va ensiklopedik ma'lumotlar **o'zbek tilida (lotin alifbosida)** tayyorlangan. Xalqaro ilmiy ixtiologik standartlarga binoan, barcha baliq turlarining ilmiy nomlari aniq lotin tilida saqlangan (*Pseudotropheus demasoni*, *Symphysodon discus*, va h.k.).

## 🌟 Asosiy Imkoniyatlar va Bo'limlar

### 1. 📚 Raqamli Baliqlar Atlasi (Fish Atlas)
- **Afrika cichlidlari (Malavi, Tanganika, Viktoriya ko'llari):**
  - Malavi: *Mbuna*, *Haps*, *Aulonocara (Tovus cichlidlari)*, *Utaka*, *Boshqa Malavi turlari*.
  - Tanganika: *Shell Dwellers (Chig'anoq cichlidlari)*, *Julidochromis*, *Neolamprologus*, *Altolamprologus*, *Cyphotilapia (Frontosa)*, *Tropheus*, *Xenotilapia*, *Calvus*.
  - Viktoriya ko'li va boshqa Afrika daryolari.
- **Amerika cichlidlari:**
  - Janubiy Amerika (*Pterophyllum scalare / Skalyariya*, *Mikrogeophagus ramirezi*, *Astronotus ocellatus / Oskar*, *Apistogramma*).
  - Markaziy Amerika (*Thorichthys meeki / Olovli og'iz*, *Amatitlania nigrofasciata*).
  - Shimoliy Amerika (*Herichthys carpintis*).
- **Diskuslar (Symphysodon):**
  - Wild Diskuslar (*Symphysodon discus / Heckel*, *S. tarzoo*, *S. haraldi*).
  - Selektsion morflar (*Pigeon Blood*, *Snake Skin*, *Cobalt Blue*).
  - Rangli mutatsiyalar (*Albino*, *Leopard Skin*).
- **Boshqa chuchuk suv baliqlari va umurtqasizlar:**
  - Tetralar, Barbuslar, Rasboralar, Danio, Guramilar, Bettalar (Xo'rozcha baliq), Tirik tug'uvchilar (Guppi, Molliya, Mechenosets, Petsiliya), Qalqonli somlar (Koridoraslar), Zanjirli yopishqoq somlar (Pleko, Antsistrus), Botiyalar va Vyunlar, Kamalak baliqlari, Killifish, Krevetkalar (*Neocaridina*, *Caridina*), Mollyuskalar.

### 2. 📑 10-Tabli Mukammal Baliq Profili
Har bir turning kartochkasida qulay tugmalar orqali quyidagi bo'limlarni ko'rish mumkin:
1. **📋 Umumiy / Asosiy:** Tavsif, o'lchami, tana tuzilishi, jinsiy dimorfizm, xulqi, qiyinligi.
2. **💧 Suv parametrlari:** Harorat (°C), pH, GH, KH, minimal va tavsiya etilgan hajm.
3. **🍽️ Oziqlantirish:** O'simlik, oqsil balansi, maxsus parhez talablari (bloat xavfi).
4. **🥚 Ko'payish:** Turi (Mouthbrooder, Substrate spawner, Bubble nest, Livebearer), inkubatsiya va chavoqlar parvarishi.
5. **🧬 Genetika va morflar:** Yovvoyi va selektsion chiziqlar, F0/F1/F2 avlodlar.
6. **🗺️ Tabiiy muhit (Locality):** Ko'l, daryo, biotop, sohillar.
7. **🔍 O'xshash turlar:** Farqlar va adashish sabablari.
8. **📚 Manbalar va Ishonchlilik:** 🟢 Ilmiy tasdiqlangan / 🟡 Akvarium amaliyotida tekshirilgan.
9. **📸 Foto galereya:** Haqiqiy suratlar va AI-tasvirlar ogohlantirishi bilan.
10. **⭐ Sevimlilar (Favorites):** Shaxsiy ro'yxatga saqlash.

### 3. 🔍 Aqlli Qidiruv va ⚖️ Taqqoslash
- **Qidiruv:** Ilmiy nom, o'zbekcha/inglizcha/ruscha nomlar, sinonimlar va savdo brendlari bo'yicha tezkor fuzzy qidiruv.
- **Taqqoslash (Comparison):** Ikkita turli turning suv parametrlari, hajmi, o'lchami va xarakterini yonma-yon solishtirish.

### 4. 🧮 8 ta Akvarium Kalkulyatori
1. **Akvarium hajmi (Litr):** Uzunlik × Kenglik × Balandlik (sm) asosida.
2. **Suv almashtirish:** Hajm va foiz bo'yicha toza suv hisobi.
3. **Isitgich quvvati (Watt):** Litrga mos isitgich tavsiyasi.
4. **Filtr oqimi (L/soat):** Soatiga 4-6 marta aylanish talabi.
5. **Kompressor / Aeratsiya:** Kislorod oqimi quvvati.
6. **Aholi zichligi (Stocking):** Baliq o'lchami va sig'im munosabati.
7. **Tuz dozasi (g):** Profilaktik yoki terapevtik sho'rlik darajasi.
8. **Oziqlantirish me'yori:** Taxminiy kunlik ozuqa miqdori.

### 5. 🏠 Mening Akvariumim & 📖 Ko'paytirish Kundaligi
- Foydalanuvchilar o'z akvariumlarini qo'shishi, ularga baliqlar biriktirishi va parametrlarini kuzatishi mumkin.
- Shaxsiy baliq tuxum qo'yishi va nasl olish kundaligi.

### 6. 🩺 Baliq Kasalliklari & 📖 Lug'at & 📰 Maqolalar
- **Kasalliklar:** Ixtioftirioz, Geksamitoz, Suzgich chirishi, Dropsy (Bloat), Oodinioz belgilari, sabablari, dori vositalari va oldini olish choralari.
- **Lug'at:** pH, GH, KH, TDS, Azot sikli, Mbuna, Utaka, Dimorfizm kabi atamalar.
- **Maqolalar:** Azot aylanishi, Malavi cichlidlari parvarishi bo'yicha professional tushuntirishlar.

### 7. 🛡️ Xavfsizlik, Middleware va Admin Panel
- **Anti-Spam (Rate Limiting):** Foydalanuvchi so'rovlarini cheklash.
- **Xatoliklar ushlovi (Error Handling):** Crash bo'lmasdan do'stona xabarlar berish.
- **Audit Logging:** Har bir harakatning bajarilish vaqti va jurnali.
- **Admin Panel:** Statistika (foydalanuvchilar, turlar, ko'rishlar), yangi turlar qo'shish va shikoyatlarni boshqarish.

## 🚀 Ishga Tushirish Yo'riqnomasi

### 1-usul: Docker & Docker Compose orqali (Tavsiya etiladi)

1. Ushbu loyiha papkasiga kiring:
   ```bash
   cp .env.example .env
   ```
2. `.env` faylini ochib, o'zingizning Telegram Bot Tokeningizni kiriting:
   ```env
   BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
   SUPER_ADMIN_IDS=sizning_telegram_id
   ```
3. Docker Compose bilan ishga tushiring:
   ```bash
   docker compose up -d --build
   ```
4. Baza jadvallarini to'ldirish (seed) uchun:
   ```bash
   docker compose exec bot python scripts/seed.py
   ```

---

### 2-usul: Mahalliy (Local) Python orqali

1. Virtual muhit yaratish va faollashtirish:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/macOS:
   source .venv/bin/activate
   ```
2. Kerakli kutubxonalarni o'rnatish:
   ```bash
   pip install -r requirements.txt
   ```
3. `.env` faylini sozlash:
   ```bash
   cp .env.example .env
   ```
   PostgreSQL bazasi ulanish manzilini va `BOT_TOKEN`ni kiriting.
4. Jadvallarni yaratish va ma'lumotlarni yuklash:
   ```bash
   python scripts/init_db.py
   python scripts/seed.py
   ```
5. Botni ishga tushirish:
   ```bash
   python main.py
   ```
